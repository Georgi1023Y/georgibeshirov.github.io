## How To Run 🧪

### 1) Prerequisites ✅

- 🟢 Node.js 20+
- 📦 npm 10+
- 🛢️ A Supabase project
- 🧭 (Optional but recommended) Supabase CLI

### 2) Install dependencies 📥

```bash
npm install
```

### 3) Configure frontend environment 🔑

Create `.env` in the repository root:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4) Set up Supabase database + Edge Function ☁️

- Apply SQL migration from `supabase/migrations/` (Dashboard SQL editor or CLI).
- Deploy Edge Function `submit-contact`.
- Configure Edge Function secrets in Supabase Dashboard:
  - `SUPABASE_URL`
  - `SUPABASE_SERVICE_ROLE_KEY`
  - `RESEND_API_KEY`
  - `NOTIFY_TO_EMAIL`
  - `RESEND_FROM`

### 5) Start development server ▶️

```bash
npm run dev
```

Open the app at `http://localhost:5173`.

### 6) Production build 🏁

```bash
npm run build
npm run preview
```
